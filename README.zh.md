# 理解现代大语言模型系统

### 从 RAG 到全景

[English](README.md) · [中文](README.zh.md)

一本免费的、完整篇幅的指南，讲清楚现代大语言模型系统到底怎么运作——RAG、微调、Agent，以及你的数据去了哪里。写给需要理解这些系统、但不打算读论文也不打算写代码的人。

**📖 免费在线阅读：**[llmknowledge1.pages.dev/zh/](https://llmknowledge1.pages.dev/zh/) · English: [llmknowledge1.pages.dev](https://llmknowledge1.pages.dev)

## 写给谁

- 产品经理、售前与解决方案工程师，以及正在转入 AI 相关岗位的人
- 需要对 AI 项目做安全或合规评审的人
- 在会议里反复听到 RAG、Agent、MCP，想要一张完整的地图、而不是一堆碎片的人

不需要任何数学或编程背景。

## 不适合谁

如果你的工作是大模型训练或推理优化，这本书对你来说会偏入门。它讲的是这些系统如何组合在一起，不教具体实现。

## 和其他资料的区别

- **建立在一手来源上。** 11 条脚注指向原始论文和官方文档，每一个不那么显然的说法都可以追溯和核对。
- **7 张原创示意图。** 每个系统都画一次、画清楚，而不是用大段文字描述。
- **一个贯穿全书的例子。** 同一个场景串起所有章节，每个新概念都落在你已经熟悉的语境里。
- **两个完整版本。** 中文和英文，内容相同。
